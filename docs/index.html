Clicky for Linux: 3D gallery

Each model below was built live by Clicky while it answered a spoken question. Nothing is pre-made: this page replays the lesson with the same engine the app runs. Drag a model to rotate it, tap a part to pick it.

Code on GitHub Demo video (2:47)

In the app a voice speaks each line. Here the captions stand in for it.

How a model gets built in seconds

Claude doesn't write a mesh. It writes a short program, one part per line, and the engine turns each line into lit, bevelled geometry on the GPU. Lines run the moment they arrive, so the model grows while Claude is still writing, and each part appears in time with the words about it.
